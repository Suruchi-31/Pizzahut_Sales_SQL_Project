# Pizzahut_Sales_SQL_Project
🍕 PizzaHut Sales Analysis using SQL
📌 Overview

This project focuses on analyzing PizzaHut sales data using PostgreSQL and SQL queries.

The dataset was imported from CSV files into PostgreSQL tables, and SQL queries were used to analyze sales performance, customer ordering patterns, and product insights.

Database and Tools
• PostgreSQL

• pgAdmin 4

🗂 Database Schema

The project contains the following tables:

Orders
Orders_details
Pizzas
Pizza_types
